# 02 — 아바타 강화 (결 문양 + 포즈 변주)

## 배경
Muse의 신원은 '결(紋)' 문양이다 — 11개 레이어 조합의 결정적 문양. 현재 아바타는 무지 크림색이라 신원이 안 읽힌다.

## 할 일 (build_scene_v2.py에서)
- 후드 상단 또는 몸통 전면에 결 문양을 얹는다: 얇은 원형 디스크(반경 0.16)에 Emission 머티리얼(따뜻한 앰버 1.6)로 단순화된 문양 — 동심원 2개 + 방사 라인 6개 + 작은 점 3개를 얇은 박스/원통으로 조립한 '문양 엠블럼'을 만들어 후드 앞쪽에 부착. 복잡한 실제 문양이 아니라 '문양이 있다'고 읽히는 수준이면 된다.
- 포즈 변주 2종을 별도 오브젝트 세트로: (a) 서 있는 Muse (몸통을 세로로 길게, 의자 없음, 발 위치 조정) (b) 걷는 Muse (몸통 기울기 6°, 팔 전후 교차, 발 앞뒤 분리).
- 변주 3종(앉음 기존 포함)을 한 프레임에 나란히 세운 시트 렌더.

- 완료 기준: 세 포즈가 구분되고, 모든 변주에 문양 엠블럼이 보인다.
