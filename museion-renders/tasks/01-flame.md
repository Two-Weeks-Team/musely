# 01 — 불꽃 강화

## 문제
현재 불꽃(Flame/FlameL/FlameR/FlameIn)이 매끈한 원뿔이라 '고깔모자'처럼 읽힌다. 스틸에서 가장 약한 부분이다.

## 할 일 (build_scene_v2.py에서)
- 불꽃 메시를 변형한다: 원뿔 정점에 결정적 노이즈(시드 고정) 지터를 넣어 실루엣을 불규칙하게. 높이에 따라 반경이 흔들리는 프로파일(아래 1.0 → 중간 0.75 → 위 0.45 → 끝 0.05) 사용.
- 층을 4개로: 바깥(주황, Emission 3.0) / 중간(밝은 주황 4.5) / 안쪽(노랑 6.0) / 심(거의 흰 노랑 8.0). 각 층은 높이·반경이 다르고 살짝 기울인다.
- 불티: 개수 34 → 48, 크기 분포를 넓히고(0.012–0.05), 상승 궤적을 나선형으로 (각도 오프셋이 높이에 비례).
- 통나무 사이에 작은 잔불 글로우 디스크 1개 (반경 0.5, Emission 1.2) 추가해 바닥 빛 번짐을 만든다.
