## 복사 가능한 실행 지시

이 문서와 이슈 인덱스·공통 계약·해당 태스크 실행 명세를 읽고 PR #31 및 #32~#69를 전체 계획으로 읽고 S1 프리뷰부터 완료한다. P-07 #46 수용 후 S2·S3를 연속 진행한다. 제출은 S3, S4는 그 뒤다. 실제 제출·공개 전환은 별도 실행 권한을 확인한다. 목적은 내 Muse가 장소 위 세계에서 성격/목표에 따라 생활·소통하고, 신원/위임이 행동을 통제하며 보상이 다음 행동을 바꾸는 제품이다. 프리뷰 → 구현 → 데모(개발 완료) → GTM 네 단계를 따른다. 먼저 현재 PR/작업 소유권을 확인하고 P-01 #40 → 선행 태스크 → P-07 #46 순으로 프리뷰 경험을 확정한다. 이슈를 읽었다는 보고로 끝내지 말고 태스크별 수용 기준과 증거를 남긴다. 이미 승인된 조사·일반 구현 선택은 반복해서 묻지 않는다. 외부 제출/공개 전환/별도 배포 권한은 이 인계로 넓히지 않는다.

1. 해당 이슈의 고정 줄 링크·선행·기존 PR·파일 소유권을 확인한다.
2. 수용 기준을 재현하고 필요한 API는 현행 공식 계약과 실제 요청으로 확인한다.

4. 독립 검토에서 타당한 지적을 반영하고 PR/commit/실행 환경/증거를 이슈에 기록한다.
5. 승인된 환경에서만 배포하고 URL/deployId/config/SHA·실제 사용자 화면을 대조한다. 에뮬레이션과 실기기를 분리한다.
