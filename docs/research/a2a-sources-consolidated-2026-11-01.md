## A2A / identity
- Official spec: https://a2a-protocol.org/latest/specification/ — AgentCard fields: name, description, supportedInterfaces, provider, version, capabilities, securitySchemes, securityRequirements, skills, signatures (JWS). https://a2a-protocol.org/latest/topics/what-is-a2a/ — discovery via /.well-known/agent-card.json, auth step parses securitySchemes -> token/JWT, then SendMessage/SendStreamingMessage task lifecycle. https://a2a-protocol.org/latest/whats-new-v1/ — v1.0: JCS RFC8785 + JWS RFC7515 for card signing, OAuth2/OIDC, MCP complementary (MCP tools/resources, A2A agent-agent).
- Key gap (analysis sources): A2A signs only the card, not messages/tasks; spec supplies evidence not policy — which keys/registries to trust, who may invoke which skill, is implementer's job. https://www.aicassindra.com/blogs/a2a/a2a_trust_models.html and .../a2a_protocol.html
- ERC-8004 Trustless Agents, proposed 2025-08-13 by De Rossi (MetaMask), Crapis (EF), Ellis (Google), Reppel (Coinbase), Draft, mainnet Jan 29 2026 per secondary: Identity Registry ERC-721 agentId + agentURI registration file (can list A2A/MCP/DID/ENS), Reputation Registry signed feedback, Validation Registry (stake re-execution / zkML / TEE). https://www.concordium.com/article/erc-8004-explained-what-it-solves-and-the-gap-it-leaves
- NANDA (MIT Media Lab, launched May 14 2025): DNS/ICANN-like registry, credentials, interoperability, attestation; Nanda Index, NandaTown sandbox. https://www.media.mit.edu/projects/mit-nanda/overview/
- Enterprise identity (GA by Oct 2026 per vendor-comparison sources, flag dates as secondary): Microsoft Entra Agent ID (blueprint + sponsor, GA ~Apr-May 2026), Okta Agent SSO / Okta for AI Agents (Universal Directory, short-lived tokens), Auth0 for AI Agents (Token Vault, async approval, FGA for RAG, GA Nov 19 2025), Google Cloud Agent Identity (SPIFFE per-agent), AWS Bedrock AgentCore Identity (GA Oct 13 2025). https://www.usecarly.com/blog/agent-identity/ ; https://www.agenticfabriq.com/blog/identity-providers-ai-agent-management
- Skyfire: KYA Know Your Agent, Agent Passports carrying reputation, verified identity + payment credentials; $8.5-9.5M seed (sources differ slightly). https://www.cbinsights.com/research/14-repeat-founders-building-agentic-commerce/
- Nevermined: metering/billing/settlement, supports x402/A2A/AP2 + ERC-8004 per secondary. https://metamarkets.substack.com/p/whos-actually-building-agentic-rails
- DID/VC pattern: DID (did:web / did:key etc) resolves to DID doc w/ keys + endpoints; capabilities/permissions as W3C VCs, scope-narrowing delegation chains, OAuth/SPIFFE for permissions. https://identigate.com/blog/posts/2026-06-26-what-is-know-your-agent-kya-and-why-should-you-care/
